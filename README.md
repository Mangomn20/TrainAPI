# TrainTrack

TrainTrack is a small Java desktop application built primarily for educational purposes. It was developed to explore API integration, XML parsing and JavaFX application development using Irish Rail's real-time data API.

## Technologies Used
- Java 21
- JavaFX
- Irish Rail Real-Time API
- XML / DOM Parser
- Java HTTP Client

## Concepts & Techniques
- Sending HTTP GET requests and handling API responses
- Parsing XML data using the DOM API
- Object-oriented programming
- Separating application logic across classes
- Working with JavaFX layouts, controls and event handling
- Displaying API data in a graphical interface

The project served as practical experience in connecting a Java application to an external API and presenting structured data through a desktop interface.
